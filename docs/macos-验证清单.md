# macOS 验证清单

Time 是一个本地时间记录桌面应用，界面为中文。这份清单用于在一台 Apple Silicon Mac 上确认它能正常安装、记录和导出。请按顺序做，遇到与"预期"不符的地方截图并记下编号。

产物由 GitHub Actions 构建，是**免安装的 `Time.app`**，不需要运行安装程序。

## 一、安装（macOS 15 Sequoia 及以上）

1. 双击 `Time-macos-arm64.zip` 解压，得到 `Time.app`。
2. 把 `Time.app` 拖进「应用程序」文件夹。
3. 双击 Time —— 会弹「Apple 无法验证"Time"是否包含恶意软件」，点 **完成**。
4. 打开「系统设置 → 隐私与安全性」，滚到最底部，点 **仍要打开**，输入开机密码，再点 **打开**。

第 3 步必须先做过，否则第 4 步的「仍要打开」按钮不会出现。这个操作只需一次，之后都是普通双击。

## 二、安装（macOS 14 Sonoma 及更早）

1、2 同上；第 3 步改成：**右键点 `Time.app` → 打开 → 在弹窗里再点「打开」**。

## 三、验收清单

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开 App | 窗口标题为「时间记录」，顶部有「记录 / 周视图 / 设置」三个入口 |
| 2 | 记录页点「打卡」 | 待补全列表多出一条只有开始时间的记录 |
| 3 | 手动填起止日期与时间、内容、选一个标签后保存 | 记录出现在下方历史里，起止时间正确（按北京时间） |
| 4 | 编辑历史里的一条记录，改内容后保存 | 列表立即显示新内容 |
| 5 | 删除一条记录并确认 | 该记录消失，没有报错 |
| 6 | 切到「周视图」 | 七天 00:00–24:00 网格；上方有「某日已记录 / 本周 / 累计」三张卡片，四类时长单调递增 |
| 7 | 点网格里的时间块 | 页面滚动到上方详情，标题是起止时间、正文是内容 |
| 8 | 周视图底部「导出图片」，用默认「下载」目录导出 | 系统可能弹「Time 想访问"下载"文件夹」，点允许；随后图片文件出现在「下载」里 |
| 9 | 设置 →「备份与恢复」→ 导出备份 | 出现 `Time_backup.sqlite3`，并提示保存位置 |
| 10 | 按 Cmd+Q 退出，再重新打开 | 第 2–5 步的记录全部还在 |
| 11 | 设置 →「修改主题」→ 切暗色 / 亮色 / 跟随系统 | 整个界面配色随之变化，文字仍清晰 |
| 12 | 把窗口拖到最小尺寸，再放大 | 布局不重叠、不溢出，按钮仍可点 |
| 13 | 在日期/时间控件上用触控板双指滚动 | 能滚到目标分钟并停住，不会越过好几格 |
| 14 | （可选，需要同步码）设置 →「云端同步」→ 填入同步码 → 立即同步 | 提示同步成功；网页版 https://zgzlcc.github.io/time 能看到同样的记录 |

## 四、数据位置（排查时用）

记录保存在：

```
~/Library/Application Support/com.time.tracker/time-v3.sqlite3
```

导出图片和备份默认在 `~/下载`（Downloads）。

## 五、发现问题怎么反馈

每条都请给：**清单编号 + 截图 + 你做了什么 + 看到什么**，外加你的 macOS 版本（「系统设置 → 通用 → 关于本机」）。截图里如果出现报错文字，请截完整的弹窗，不要裁剪。

## 六、已知限制

- 应用未做 Apple 签名与公证，首次打开需要上面「仍要打开」那一步。
- 没有自动更新，换版本需要重新下载替换 `Time.app`；记录不受影响。
- 首次向「下载」或「桌面」写入时会弹一次系统授权，允许后不再提示。
- 云端同步依赖代理：国内直连 `*.workers.dev` 不可用，未开代理时同步失败，但不影响本地记录。
